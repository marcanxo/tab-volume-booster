Tab Volume Booster는 슬라이더 하나로 어떤 브라우저 탭이든 소리를 최대 6x까지 키우거나, 완전한 무음까지 줄일 수 있는 확장 프로그램입니다.

• 소리가 작은 영상, 통화, 강의, 스트리밍을 100% 이상으로 부스트하세요.
• 반주를 내 악기보다 작게 낮출 수도 있습니다. 기타 소리 아래로 곡을 은은하게 깔고 연습하고 싶을 때 딱 좋습니다.
• 전체 화면 친화적: YouTube를 비롯한 대부분의 사이트에서 페이지 자체 오디오를 조절하므로, 부스트 중에도 기본 전체 화면이 그대로 작동합니다.
• 탭별 설정: 각 탭이 자신의 볼륨 레벨을 따로 기억합니다. 다른 탭과 공유되지 않으며, 탭을 닫으면 사라집니다.
• 안정적: 페이지 새로고침이나 “다음 화” 전환에도 설정이 유지되고, 플레이어가 교체되어도 영상을 계속 따라갑니다. 강한 부스트 시 왜곡을 잡아 주는 리미터도 내장되어 있습니다.
• 클릭 한 번이면 원래 상태로 초기화됩니다.
• 14개 언어를 지원합니다. 번역은 커뮤니티 기여로 이루어지며, 참여 방법은 GitHub 저장소를 참고하세요.

개인정보: 모든 동작이 사용자의 기기 안에서만 이루어집니다. 업로드되는 데이터가 없고 분석 도구나 광고도 전혀 없으며 어떤 데이터도 수집하지 않습니다.

오픈 소스(GPL-3.0): https://github.com/marcanxo/tab-volume-booster

참고: DRM 보호 사이트(Netflix, Spotify, Disney+ 등)는 페이지 내에서 조절할 수 없어 캡처 모드로 부스트합니다. 이 경우 부스트 중에는 전체 화면을 사용할 수 없습니다.
